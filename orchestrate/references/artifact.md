# Artifact orchestration

Use this workflow for documents, decks, designs, diagrams, presentations, and other human-facing deliverables.

## Intake and decomposition

Establish the audience, objective, required format, source material, visual or editorial constraints, and definition of done. Split only when sections can be produced without conflicting edits; otherwise use one doer.

Tell each doer to report the output path, sources used, requirement checklist, and unresolved editorial decisions.

## Validation

Do not add an independent reviewer merely as ceremony. The coordinator inspects the completed artifact against the brief. Use the relevant rendering, preview, or format-specific verification when visual layout or file integrity matters.

Check:

- audience fit and objective;
- factual consistency with supplied sources;
- completeness against required sections;
- readability, structure, and visual hierarchy;
- output path and format integrity.

Route focused fixes to the original doer, then re-inspect the changed portion.
